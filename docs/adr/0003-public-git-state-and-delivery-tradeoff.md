# 公开 Git 分支持久化阶段状态并优先少漏推

Actions runner和cache不能作为可靠长期状态，读者允许公开兴趣与日报且希望不另搭服务器，因此将非敏感阶段状态、已验证总结与不可变发送快照保存在专用Git分支，而非只cache或外部数据库。微信异步发送与Git提交无法形成一个事务，故保留unknown并允许有限标记补发、接受少量重复以减少漏推；SendKey/readkey只在运行时使用，不为跨run确认把秘密写进公共历史，已发送副作用和公开状态历史的迁移成本使这成为需保留理由的架构取舍。
