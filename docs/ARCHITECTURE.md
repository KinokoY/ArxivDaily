# 架构与行为

Python 批处理应用，没有网页界面或独立数据库。Actions 负责启动，状态分支保存可恢复 JSON 状态及 Markdown 历史。

| 模块 | 职责 |
| --- | --- |
| cli / config / prompts | 命令、配置校验、提示加载 |
| collection / rules | arXiv 分页、日期窗口、宽召回 |
| llm / fulltext / translation | 终筛、正文/图表、复审总结、翻译 |
| pipeline | 阶段编排、篇数/费用预算、恢复、索引 |
| models | 论文、判断、内容与事件结构 |
| state | 原子保存、运行锁、检查点、脱敏 |
| render / delivery | Markdown、通知容量、Server酱结果 |
| simulation | 明确标注的离线实现 |
| upstream / _vendor | 固定上游元数据规范化 |

## 核心约定

初筛宽召回，不决定相关性；标题默认不参与关键词，但作为候选模型输入。多分类、多路线合并到同一基础 arXiv ID。

终筛 select/reject/uncertain 三态。summary 模式有限复审 uncertain；完整总结使用合格的具体版本正文，HTML 优先、PDF 回退，必要时读图表。长文分片提取证据，不只截前缀。内部保存定位和引文，校验数字；公开正文不展示证据定位列表。

translation 不读正文，select/uncertain 提供完整双语摘要并标不确定性。全文名额溢出为轻量，不自动形成次日全文积压。已确认基础 ID 不因修订、模式、配置、提示变化自动重发。

总索引覆盖规则候选；中文标题独立翻译，失败不丢行。正常无新增仍通知，失败单独报告。正文按 UTF-8 字节控制容量，整篇移到公开归档，不截半篇。

## 内容生命周期

main：代码、配置、提示、测试。arxivdaily-state：state.json、可变日期汇总/总索引、不可变发送快照。

成功内容跨运行复用，实际提示指纹随阶段记录；section_notes 内容影响长文缓存键。新提示不自动清除成功结果。副作用前保存检查点，发布失败阻止继续；发送确认与保存间仍有未知结果边界，用 unknown 和有限补发处理。

原文/PDF/图像/临时文件/密钥不写公开状态；readkey 仅单次运行内存存在，隐藏推理和原始 provider 响应不进入公共归档。

规则、参数与任务提示从两个入口调整；新增输出类别、改变档位/证据规则、状态格式属于代码迭代。核心源码维持 app，避免同时迁移安装契约。
