## 用户已确认的核心范围

- Python，通过 arxiv Python 库采集；基于 MIT `X-PG13/paper-digest` 二次开发，替换采集和 LLM/全文流程。
- 单用户配置文件批处理，公开代码、兴趣配置、记录和 Markdown 日报；GitHub Actions 标准免费 runner 每日北京时间 15:17 执行，持久状态放专用分支。
- 初筛偏召回、终筛偏精度。关键词仅匹配摘要；标题用于展示和 LLM 输入，标题关键词不默认开启；分类可扩展、接受交叉分类。取消全文关键词检索，保留全文总结与有限证据核查。
- 四类重点兴趣：医学推理分割、医学分割 DPO/RL/拓扑目标、通用推理分割 + RL/DPO、传统/SAM 的实质损失设计 + 理论 + 迁移价值。传统 loss 摘要证据不足可有限读全文，复核后再推送。
- **独立轻量档位：通用无 RL/DPO 的推理分割只列标题和链接。** 用户明确非常喜欢这一档位；它独立于全文总结与每日完整总结篇数档位，不自动进入昂贵总结。
- 完整总结通常 5 篇、每天上限 10 篇、不足不凑；超量保留标题等简要信息。中文背景/贡献/方法/实验/结论五段六句为长度目标，准确性优先，保留重要实验数字与出处。
- 总结读取合格正文、可提取表格/图注和必要图表；全文失败待处理重试，不用摘要代替全文总结。
- 官方 DeepSeek `https://api.deepseek.com`，两个角色均用 `deepseek-flash`：**终筛思考中等，总结思考极高**，分别配置输入、输出、超时和重试预算。原 `none/low` 与总结 `high` 推荐已被用户最新回答覆盖。
- **不设 50 元/月强制预算；用户自行管理余额。** 费用记录与可配置保护仍保留，这是明确选择，不是缺少预算信息。
- 微信用 **Server酱 Turbo 免费账号**，首版不依赖会员、付费或 7 天试用权益；按实际体验以后迭代。每天合并一条 Markdown 日报、点击详情阅读、完整版/历史保存公开 GitHub Markdown，无需默认邮件或 GitHub Pages。
- 新论文只推一次，修订不重推；首次回溯 7 天；少漏推优先，极端确认/状态边界允许偶尔重复；自动补采最多 14 天，超界提示手动补采，每阶段有限重试。
- 无结果静默，部分成功先推可用结果，整次失败告警；验收覆盖代表 ID 独立回放、完整分页/去重/兴趣边界、正文失败、图表数字出处、JSON 损坏/截断、部分成功与 Secrets。
