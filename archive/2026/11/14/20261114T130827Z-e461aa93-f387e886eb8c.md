### SpaceMCP: Vision Language Model Spatial Reasoning via Model Context Protocol

**中文标题：** SpaceMCP：通过模型上下文协议实现视觉语言模型的空间推理

**摘要：** Despite impressive advances in large language models (LLM), vision-language models (VLM) still exhibit limited spatial reasoning capabilities. Recent progress in feed-forward 3D reconstruction has enabled precise, real-time geometric understanding from visual inputs. In this work, we propose SpaceMCP, a framework that leverages these advances to introduce an MCP-style paradigm for spatial reasoning. Our approach augments a VLM with structured function calls, allowing it to query a scene graph for spatial information such as distances, object positioning, and camera properties. The scene graph is constructed in real time using feed-forward 3D reconstruction to recover metric geometry, combined with open-vocabulary segmentation to identify and localize relevant objects within the scene. Paired with the VLM's strong reasoning capabilities, the VLM is able to combine this primitive information to solve more complex spatial tasks. Without any training, SpaceMCP achieves state-of-the-art results on VSI-Bench, MMSI-Bench and VSTI-Bench, outperforming recent spatially post-trained VLMs and improving its base VLM by 15-22 points per benchmark. We argue that, given the contrast between the relatively slow progress in native VLM spatial reasoning and the rapid advances in feed-forward 3D computer vision, this paradigm offers a promising path forward for enabling robust spatial reasoning.

**摘要翻译：** 尽管大语言模型（LLM）取得了令人瞩目的进展，视觉语言模型（VLM）的空间推理能力仍然有限。前馈三维重建的最新进展使得从视觉输入中进行精确、实时的几何理解成为可能。在本工作中，我们提出 SpaceMCP，一个利用这些进展为空间推理引入 MCP 式范式的框架。我们的方法通过结构化函数调用增强 VLM，使其能够查询场景图以获取距离、物体定位和相机属性等空间信息。场景图利用前馈三维重建实时构建以恢复度量几何，并结合开放词汇分割来识别和定位场景中的相关物体。结合 VLM 强大的推理能力，VLM 能够组合这些基础信息来解决更复杂的空间任务。在无需任何训练的情况下，SpaceMCP 在 VSI-Bench、MMSI-Bench 和 VSTI-Bench 上取得了最先进的结果，超越了近期经空间后训练的 VLM，并在每个基准上将其基础 VLM 提升了 15-22 个点。我们认为，鉴于原生 VLM 空间推理进展相对缓慢与前馈三维计算机视觉快速发展之间的反差，这一范式为实现稳健的空间推理提供了一条有前景的路径。

### Where is My Mug? Training-Free Framework for Personalized Image Segmentation

**中文标题：** 我的马克杯在哪里？面向个性化图像分割的无训练框架

**摘要：** \textbf{Personalized Image Segmentation (PIS)} aims to segment the specific object in a target image that matches a user-provided reference. Unlike category-based segmentation or few-shot segmentation, PIS must discriminate between multiple visually similar instances, a requirement central to deployed applications such as augmented reality, personalized content editing, robotics manipulation, inventory tracking, and fine-grained visual retrieval. We show that the strong numbers reported by existing PIS methods are largely an artifact of single-instance benchmarks: when evaluated on realistic scenes with several same-category look-alikes, prior point-prompt methods collapse, because the correct instance is frequently never surfaced as a prompt. We trace this to a recall bottleneck rather than a mask-quality one, and address it with a training-free, modular system. The pipeline first generates high-recall object proposals using an off-the-shelf class-agnostic detector, then matches each proposal to the reference using foundation-model features (e.g., BLIP-2), and finally refines the selected box with SAM. For robust matching we propose \textbf{top-$K$ Sinkhorn}, a patch-level distance that scores each candidate only on its most confidently matched patches; trimming the Sinkhorn dual potentials recovers the robustness of partial optimal transport at more than $100\times$ lower cost, keeping it inside the per-proposal candidate loop. To evaluate this regime, we introduce \textbf{\datasetname}, a realistic multi-instance benchmark. Across \datasetname, PerSeg, PerMIS, and DAVIS, our system surpasses PerSAM, $\mathrm{P}^2\mathrm{SAM}$, and PDM by up to $\sim\!48$ mIoU while matching their runtime and using fewer parameters, establishing a strong, deployable training-free baseline for real-world personalized segmentation.

**摘要翻译：** \textbf{个性化图像分割（PIS）}旨在分割目标图像中与用户提供的参考相匹配的特定对象。与基于类别的分割或少样本分割不同，PIS 必须区分多个视觉上相似的实例，这一需求对于增强现实、个性化内容编辑、机器人操作、库存跟踪和细粒度视觉检索等部署应用至关重要。我们表明，现有 PIS 方法所报告的强劲数值在很大程度上是单实例基准的假象：在具有多个同类相似物的真实场景中评估时，先前的点提示方法会崩溃，因为正确的实例经常从未作为提示出现。我们将此归因于召回瓶颈而非掩码质量瓶颈，并用一个无需训练、模块化的系统来解决它。该流程首先使用现成的类别无关检测器生成高召回的对象提议，然后使用基础模型特征（例如 BLIP-2）将每个提议与参考进行匹配，最后用 SAM 细化选定的边界框。为实现稳健匹配，我们提出 \textbf{top-$K$ Sinkhorn}，这是一种块级距离，仅根据每个候选最自信匹配的块来对其评分；修剪 Sinkhorn 对偶势能可以以超过 $100\times$ 更低成本恢复部分最优传输的稳健性，使其保持在每个提议的候选循环内。为评估这一情形，我们引入 \textbf{\datasetname}，一个真实的多实例基准。在 \datasetname、PerSeg、PerMIS 和 DAVIS 上，我们的系统以高达 $\sim\!48$ mIoU 超越 PerSAM、$\mathrm{P}^2\mathrm{SAM}$ 和 PDM，同时匹配它们的运行时间并使用更少参数，为真实世界的个性化分割建立了一个强大、可部署的无训练基线。

### Hint-Informed Self-Distillation for Reasoning Segmentation

**中文标题：** 提示引导的自蒸馏用于推理分割

**摘要：** Reasoning segmentation requires identifying the target referred to by a query among visually similar objects, yet trajectory-level rewards cannot directly indicate which tokens provide relevant visual evidence. We propose Hint-Informed Self-Distillation (HISD), which uses target-disambiguation evidence for token-level credit assignment. An external model generates Segment Hints offline from training images, queries, and ground-truth target annotations, organizing target identity, discriminative attributes, confusable objects, and anchoring paths. A hint-conditioned exponential moving average teacher scores the student's own trajectories, and HISD computes the teacher-to-student evidence ratio over a token support set to adjust only the magnitudes of positive group-relative advantages, leaving nonpositive advantages unchanged. This design encourages concise reasoning while retaining the information needed for target disambiguation, and the student requires neither hints nor a teacher at inference. Under a unified training protocol, HISD improves ReasonSeg test gIoU and cIoU over our reproduction of DPAD by 3.00 and 3.55 percentage points, respectively. Across the five evaluated splits of ReasonSeg and the RefCOCO family, HISD achieves higher segmentation metrics than this baseline and reduces the average token count of valid reasoning spans by 80.17 to 91.83 percent.

**摘要翻译：** 推理分割需要在视觉相似的物体中识别查询所指的目标，然而轨迹级奖励无法直接指示哪些token提供了相关的视觉证据。我们提出提示引导的自蒸馏（HISD），利用目标消歧证据进行token级信用分配。外部模型从训练图像、查询和真实目标标注中离线生成片段提示，组织目标身份、判别属性、易混淆物体和锚定路径。提示条件化的指数移动平均教师对学生自身的轨迹进行评分，HISD在token支持集上计算教师与学生的证据比率，仅调整正组相对优势的幅度，非正优势保持不变。该设计鼓励简洁推理，同时保留目标消歧所需的信息，且学生在推理时既不需要提示也不需要教师。在统一的训练协议下，HISD相比我们复现的DPAD在ReasonSeg测试集的gIoU和cIoU上分别提升了3.00和3.55个百分点。在ReasonSeg的五个评估划分和RefCOCO系列上，HISD的分割指标均高于该基线，并将有效推理片段的平均token数量减少了80.17%至91.83%。
